* **Questão 4:** `q4-rotas` (Next.js: App Router e Rotas Dinâmicas)
* **Questão 5:** `q5-mini-loja` (Next.js: Projeto consolidado com geração de JSON)

Cada pasta contém seu próprio `README.md` com instruções específicas de execução.
